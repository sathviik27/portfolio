# Sathvik | AI & Machine Learning Portfolio

An Apple-grade minimalist portfolio and engineering showcase crafted for a **1st-Year Artificial Intelligence & Machine Learning Undergrad** at **Dayananda Sagar University (DSU), Bangalore**.

Engineered with Cupertino luxury minimalism: pure obsidian blacks (`#000000`), hairline borders, frosted glass surfaces, SF Pro typography, 3D mathematical dotted wave matrix, interactive in-browser AI studio, and a dedicated native engineering journal.

## ✨ Features & Architecture

### 1. Cupertino Minimalist Design System
- **Pure Dark Palette**: Matte obsidian (`#000000`), dark graphite (`#121215`), subtle Apple jade (`#30D158`) and ruby (`#FF453A`) accents.
- **Micro-interactions & Precision**: Frosted glass surfaces (`backdrop-filter: blur(20px)`), 1px translucent hairline borders (`rgba(255, 255, 255, 0.08)`), and buttery smooth transitions.
- **3D Undulating Dotted Wave Matrix**: GPU-accelerated mathematical sine/cosine mesh projected in 3D perspective with cursor tilt and ripple dynamics.
- **Zero Modal Jank**: Layout-shift-free architecture featuring a dedicated standalone Apple-editorial reading view (`blog.html`) with smooth page transitions and `scrollbar-gutter: stable`.

### 2. In-Browser AI/ML Studio
Zero-install client-side machine learning inference:
- **VisionDigit**: Interactive 28×28 neural digit classification canvas with real-time confidence distribution.
- **SentimentPulse**: Real-time natural language sentiment analysis with tokenization and polarity scoring.
- **GradientLoss**: Live Stochastic Gradient Descent (SGD) loss trajectory visualizer with dynamic learning rates.

### 3. Engineering Journal & Research Papers
- Native markdown-rendered technical articles on foundational mathematics, matrix calculus, Java multithreading, and neural optimization.
- One-click code copy blocks with syntax highlighting.
- Clean URL query routing (`blog.html?article=<id>`) for direct sharing.

### 4. Real Academic & Project Highlights
- **VisionDigit CNN**: PyTorch MNIST classifier with 99.2% validation accuracy.
- **JavaMatrix Engine**: High-performance multi-threaded linear algebra matrix operations in Core Java.
- **SentimentPulse NLP**: Lightweight sentiment analyzer with sub-5ms inference.
- **DSU CourseSpark RAG**: Retrieval-Augmented Generation assistant indexing 1st-year DSU syllabi and past exams.

## ⚡ Getting Started Locally

Open `index.html` directly in any modern browser, or run a local web server:

### Python 3:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.

### Node / npx:
```bash
npx serve
```
